# Simple REST API with Node.js

A simple REST API built using Node.js and Express.js for managing notes.

## Features

- Create a note
- Get all notes
- Get a single note by ID
- Update a note
- Delete a note
- Input validation
- Error handling
- JSON file-based data storage

## Technologies Used

- Node.js
- Express.js
- JavaScript
- JSON
- Postman
